# GROVA WEBSITE

Corporate website starter for GROVA HOLDINGS. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- index.html — Vietnamese homepage
- styles.css — responsive design
- script.js — mobile navigation and copyright year
- .github/workflows/pages.yml — automatic deployment

## Publish
1. Open repository Settings → Pages.
2. Set Source to GitHub Actions.
3. Push to main to deploy.

Default Pages URL: https://trungythp1-jpg.github.io/GROVA-WEBSITE/

## Before public launch
Confirm official logo, company details, legal status and descriptions of subsidiaries, contact email, and rights to use grova.com. The displayed contact email is a placeholder and must be verified. Do not change DNS for grova.com until current website and email dependencies are checked.
