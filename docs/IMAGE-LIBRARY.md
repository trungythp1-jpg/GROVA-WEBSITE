# GROVA Website — Image Library Plan

## Asset folders
- `assets/images/`: hero images, project photography, cabin/interior visuals, materials, and team/work images.
- `assets/icons/`: SVG icons and small decorative brand assets.
- Keep the official logo at `assets/grova_logo.png`.

## Suggested asset names
- `hero-holdings.webp` — homepage hero visual
- `elevator-project-01.webp` — approved elevator project photography
- `interior-cabin-modern-01.webp` — approved cabin design image
- `interior-cabin-luxury-01.webp` — approved cabin design image
- `material-stainless-steel.webp`, `material-glass.webp`, `material-wood-finish.webp`
- `law-team.webp`, `education-training.webp` — only after the relevant team/program and usage rights are confirmed

## Publishing rules
1. Prefer original project photos with permission to publish.
2. Never label stock/generated imagery as a real GROVA project.
3. Use optimized WebP/AVIF where supported; keep meaningful images reasonably compressed.
4. Every informative image needs Vietnamese alt text; purely decorative images should use empty alt text or be hidden from assistive technology.
5. Confirm usage rights and obtain approval before publishing customer/site photos.
6. Add responsive image sizes and lazy loading for below-the-fold images.
